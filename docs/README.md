# litegm 文档索引

本目录按读者分组织文档。首次接触项目请从仓库根目录的 [README](../README.md) 开始。

## 面向使用者

| 文档 | 内容 |
|---|---|
| [README](../README.md) | 项目定位、功能列表、快速开始、Docker 部署、配置要点、已知限制 |
| [使用说明](usage.md) | 环境准备、配置项、启动、API 调用示例、运维功能（存储/可观测/热载/免认证）、Docker、管理台使用 |
| [API 参考](api.md) | 图像/视频/音频端点、字段、响应形状、错误码、运维与管理台接口 |

## 约定

- 每个里程碑完成后在 `changelog/` 写记录并在索引中登记。
- 文档中引用的路径、端点与脚本需与代码保持一致；改动接口时同步更新 `api.md`
  与 `development.md` 的模块索引。
- 新增面向用户的能力时，优先更新 README 的功能概览与使用说明。
