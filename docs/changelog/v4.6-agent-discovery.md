# v4.6 agent discovery: `/llms.txt`, Swagger UI and enriched OpenAPI

## Motivation

The gateway was only documented for humans (README, `docs/api.md`). An agent that
was handed just a base URL had to guess model aliases and endpoint semantics, and
a developer had no interactive way to try calls without writing curl commands.
Two additions close that gap:

1. a machine-readable brief generated from the deployment's live configuration,
2. an interactive API reference and an OpenAPI document suitable for generating
   clients or tool definitions.

## Changes

- `src/litegm/docs_discovery.py` (new):
  - `llms_txt()` renders an llmstxt.org-style Markdown brief from `Config`:
    start-here links, authentication, curl/OpenAI SDK snippets, every configured
    alias with its constraints, video-family routing, image/video/audio endpoints,
    the async task protocol, the error table and operational endpoints. The master
    key is never rendered — only a `<master_key>` placeholder.
  - `openapi_extras()` adds servers, a bearer security scheme, per-endpoint
    summaries/descriptions/examples and the discovery/health endpoints that are
    outside the router schemas. A schema failure falls back to a minimal document.
  - `swagger_html()` serves Swagger UI (CDN assets) with links back to
    `/llms.txt`, `/openapi.json` and `/v1/models`.
- `src/litegm/app.py`: registers `GET /llms.txt`, `GET /swagger-ui` (`/docs` as an
  alias) and `GET /openapi.json`; FastAPI's built-in docs routes are disabled so
  the generated document is the single source. Absolute links derive from the
  request host (same rule as the admin signed links), so any port/proxy works.
  These endpoints need no bearer token: they describe the API and contain no
  secrets.
- `web/src/api.ts`, `web/src/icons.tsx`, `web/src/Shell.tsx`: top-bar "API 文档"
  link, a "llms.txt" button that copies the absolute agent link, and command
  palette entries for both.
- Documentation: README feature table + agent note, `docs/api.md` discovery
  section with the minimal agent flow, `docs/usage.md` §5.1 "把服务接入 agent
  环境", `docs/development.md` module/test index and sync rule, `docs/README.md`
  and `AGENTS.md` entries.

## Verification

- `pytest -q -m 'not integration'`: 92 passed (incl. the new
  `tests/test_docs_discovery.py`, which asserts the llmstxt.org shape, that only
  configured aliases appear, that the master key is absent, and that the OpenAPI
  document keeps FastAPI's paths while adding servers/security/examples).
- `tsc --noEmit` and `vite build` for the admin console: clean.
- Live probe against `config/litegm.yaml`: `/llms.txt` renders 227 lines with the
  configured aliases and limits; `/openapi.json` contains 38 paths, `servers` and
  `bearerAuth`.
- `fix_utf8.py` OK for every touched file; `check_doc_links.py` reports no broken
  links.

## Known limitations

- The Swagger UI loads its assets from jsDelivr; behind a restricted network the
  page still shows the links to `/openapi.json` and `/llms.txt` but no controls.
  Self-hosting the bundle would need a new dependency or vendored files.
- `/llms.txt` changes with the configuration; agents that cache it will see stale
  aliases until they refetch. It is served with `Cache-Control: no-cache`.
- The OpenAPI document is not versioned or validated against a schema; it is
  generated per request from the FastAPI routes.
- Progress values in async jobs are estimated from stage timings (see
  `docs/usage.md` §8.5), and the brief says so.
